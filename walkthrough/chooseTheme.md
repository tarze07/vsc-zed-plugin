# Pick a theme

The extension ships two muted color themes with WCAG AA contrast:

- **Zed-like Dark** — default for the layout preset,
- **Zed-like Light**.

**Apply Zed Layout** switches to the theme selected in `zedLayout.layout.theme`. Set
`zedLayout.layout.applyTheme` to `false` if you want to keep your current theme.

The terminal uses the same palette, so agent output stays readable in both themes.

[Pick Theme](command:workbench.action.selectTheme)
